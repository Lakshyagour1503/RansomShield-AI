# Project Reports

This folder is reserved for the academic documentation for **RansomShield AI — Intelligent Ransomware Detection Using Hybrid Deep Learning**.

## Reports to include

1. **Phase-I Project Report** — project problem definition, literature review, objectives, scope, feasibility, and references.
2. **Three-Week Progress Report & Research Review** — progress summary, dataset and preprocessing review, proposed model design, limitations, and next milestones.

## Document privacy

Before publishing the original reports publicly, use portfolio copies that remove student ID numbers and Turnitin/integrity-report pages. Keep the institution's academic requirements in mind and do not alter substantive academic content.

## Project status

The proposed MLP + BiLSTM design is still a plan until the compatible dataset, model training, inference backend, and evaluation are actually implemented and tested. Do not present proposed metrics as experimental results.
